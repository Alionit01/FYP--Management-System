## 🚀 Getting Started

### Prerequisites

Make sure you have Flutter installed and configured on your system.

Check your Flutter installation with:

```bash
flutter doctor
```

### Clone the repository

```bash
git clone https://github.com/Alionit01/Flutter_Practice.git
cd Flutter_Practice
```

### Get dependencies

For the Flutter project you want to run:

```bash
flutter pub get
```

### Run the project

```bash
flutter run
```

You can also select a connected Android device, emulator, or another supported Flutter target.
